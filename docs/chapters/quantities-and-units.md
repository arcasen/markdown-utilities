## 量与单位

### 国际标准

按照国际标准（如国际单位制 SI）以及国内的国家标准，在表示数字与单位时，**数字与单位之间应当留出一个半角空格**。

具体规则与示例：

**1. 基本规则**

- 正确：`50 kg`、`100 m`、`25 °C`、`10.5 s`
- 错误：`50kg`、`100m`、`25°C`

**2. 特殊情况（不需要空格的单位）**

平面角的单位——**度（`°`）、分（`′`）、秒（`″`）**，直接写在数字后面，不加空格。

- 正确：`45°`、`30′`、`15″`
- 错误：`45 °`
- `℃` 不属于这个例外：`25 ℃` 中间要有空格

**3. 百分号和千分号（`%`、`‰`）**

严格来说，百分号 `%` 在国际标准中也建议与数字之间保留一个空格（如 `50 %`），但在实际排版和日常书写中，紧贴数字（如 `50%`）更为常见且被广泛接受。类似地，`50%Pn`，属于行业约定，不是 SI 标准。

::: caution
容易混淆的场景：

1. 中文单位一般不空格：`5千克`、`10米`
2. 编号、型号不是物理量，一般不空格：`202室`、`A5`
:::

### Markdown 中的量与单位

#### 使用行内公式

- `$50\ \mathrm{{m/s}}$`：$50\ \mathrm{{m/s}}$
- `$50\ \mathrm{m\cdot s^{-1}}$`：$50\ \mathrm{m\cdot s^{-1}}$

#### 纯文本 Markdown 

- HTML 不间断空格，适合短单位：`50&nbsp;m/s` 效果为 50&nbsp;m/s
- 换负指数文本写法：`50 m·s^-1^` 效果为 50 m·s^-1^

::: caution
`m/s` 在渲染时可能被截断而跨行。
:::
